## Install

```bash
brew install aayush9029/tap/noz
```

Or tap first:

```bash
brew tap aayush9029/tap
brew install noz
```

## Usage

```bash
noz            # 45 minutes (default)
noz -m 60      # 1 hour
noz -m 5       # 5 minutes
```

Press Enter to stop early, or wait for the timeout.
